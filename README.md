# Python Summary 🐍

A collection of Jupyter notebooks summarizing core Python concepts, created while learning and practicing Python fundamentals.

## 📚 Contents
| Notebook | Topic |
|---|---|
| `types.ipynb` | Python data types |
| `if, else, elif.ipynb` | Conditional statements |
| `while break.ipynb` | While loops and break statements |
| `range().ipynb` | The `range()` function |
| `lists and types.ipynb` | Lists and type handling |
| `lists and its funcs.ipynb` | List methods and functions |
| `functions.ipynb` | Function basics |
| `functions, recursion.ipynb` | Functions and recursion |
| `input operations.ipynb` | Taking and handling user input |
| `libraries and functions.ipynb` | Working with Python libraries |
| `finding id's.ipynb` | Using `id()` and object identity |
| `class-relationship.ipynb` | Relationships between classes |
| `oops(new).ipynb` | Object-Oriented Programming basics |
| `oops(2).ipynb` | OOP concepts continued |
| `bankoperator.ipynb` | Mini project: bank operations |
| `calculator.ipynb` | Mini project: calculator |
| `practice.ipynb` | General practice exercises |
## 🚀 Getting Started

Clone the repository:

\`\`\`bash
git clone https://github.com/unnatissrivastava/python-summary.git
cd python-summary
\`\`\`

Open any notebook with Jupyter:

\`\`\`bash
jupyter notebook
\`\`\`

Or open it directly in [Google Colab](https://colab.research.google.com/) by uploading the `.ipynb` file.

## 🛠️ Requirements

- Python 3.x
- Jupyter Notebook or JupyterLab

Install Jupyter if you don't have it:

\`\`\`bash
pip install notebook
\`\`\`
